# Ландшафтный планировщик

Веб-приложение для планирования садового участка на основе фотографии.

## Возможности

- Загрузка фотографии участка.
- AI-обработка фото через **Nano Banana**.
- AI-обработка фото через **Gemini 3 Pro Image API** (через Google Generative Language API endpoint).
- Добавление растений, деревьев, кустарников и декоративных элементов.
- Перетаскивание объектов по сцене.
- Настройка масштаба и поворота выбранного элемента.
- Управление слоями (на передний/задний план).
- Экспорт итоговой визуализации в PNG.

## Запуск

Это статическое приложение: можно открыть `index.html` прямо в браузере.

Или запустить локальный сервер:

```bash
python3 -m http.server 4173
```

Открыть: `http://localhost:4173`

## Как использовать Nano Banana

1. Загрузите фотографию участка.
2. Выберите вкладку **Nano Banana**.
3. Укажите:
   - `Nano API URL` вашего endpoint,
   - `Nano API Key` (если требуется),
   - промпт обработки.
4. Нажмите **«Обработать через Nano Banana»**.

Приложение отправляет `multipart/form-data` с полями `image`, `prompt`, `output_format=png`.

## Как использовать Gemini 3 Pro Image API

1. Загрузите фотографию участка.
2. Выберите вкладку **Gemini 3 Pro Image**.
3. Укажите:
   - `Gemini API Key`,
   - модель (по умолчанию `gemini-2.5-pro`),
   - промпт обработки.
4. Нажмите **«Обработать через Gemini 3 Pro Image API»**.

Приложение отправляет запрос в endpoint:

`https://generativelanguage.googleapis.com/v1beta/models/{model}:generateContent?key=API_KEY`

с `inline_data` изображением и ожидает в ответ `inlineData` с изображением.

## Важно

- Для браузерных запросов endpoint должен поддерживать CORS.
- Если провайдер не возвращает image-part в ответе, приложение покажет диагностическую ошибку.

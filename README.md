# Ландшафтный планировщик

Веб-приложение для планирования садового участка на основе фотографии.

## Возможности

- Загрузка фотографии участка.
- Обработка фото через NanoBanana (улучшение, стилизация, предварительная подготовка сцены по промпту).
- Добавление растений, деревьев, кустарников и декоративных элементов.
- Перетаскивание объектов по сцене.
- Настройка масштаба и поворота выбранного элемента.
- Управление слоями (на передний/задний план).
- Экспорт итоговой визуализации в PNG.

## Запуск

Это статическое приложение: можно открыть `index.html` прямо в браузере.

Или запустить локальный сервер:

```bash
python3 -m http.server 4173
```

Открыть: `http://localhost:4173`

## Как использовать NanoBanana

1. Загрузите фотографию участка.
2. В блоке **«Обработка NanoBanana»** укажите:
   - `API URL` вашего NanoBanana endpoint,
   - `API Key` (если требуется),
   - текстовый промпт для обработки.
3. Нажмите **«Обработать фото через NanoBanana»**.
4. После успешной обработки продолжайте планирование на обновлённом изображении.

> Примечание: endpoint должен поддерживать CORS для запросов из браузера. Приложение отправляет `multipart/form-data` с полями `image`, `prompt`, `output_format=png` и ожидает в ответ изображение (blob) или JSON с `image_base64`/`image_url`.
